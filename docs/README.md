## Границы текущей работы

Все найденные файлы docs/ учтены при локальной сверке: актуальный комплект отделён от истории; исторические файлы не переписываются под новые требования. Архивы/отчёты ревью вне Git — доказательства состояния, не параллельный источник требований. Ни один новый критерий не объявляется PASS по факту редактирования Markdown. На этапе PM-DOC-002 DEC-036 оставался открытым. Правила AGENTS.md — инструкции исполнителю, не техническая блокировка Git; файл не меняется. В PM-DOC-002 нет сети, staging, commit, push, изменения VPS или публикации; разрешения старых задач к нему не применяются.
