## История и технические инструкции

Существующие docs/PM-* и материалы review/mockups сохраняются на местах как история с исходными базами и ограничениями; их планы не становятся автоматически текущими требованиями. Подробные контракты и runbooks не удаляются. Точки входа: [PM-000 — защита данных](PM-000-data-safety.md), [PM-002 — реестр/карточка](PM-002-project-registry-and-card.md), [архитектурный read API](PM-003B2.2-read-api.md), [архитектурная приёмка](PM-003C.4-review-report.md). Инструкция сборки/развёртывания остаётся [рядом с deployment tooling](../deploy/demo/README.md).

История решений и старые материалы не переписываются задним числом. Проверять актуальные правила/источник, если исторический документ описывает прежнюю навигацию или scope.

## Актуальное позиционирование и фиксация

ПроектПульт — демонстрационный пилот персонального интеллектуального рабочего пространства руководителя ИТ-проектов без привязки к конкретной организации, DEC-038. Продуктовая версия0.2 утверждена, scope показа/работающие AI-сценарии/дизайн/целевая архитектура согласовываются отдельно. Локальная фиксация подтверждается фактическим commit в истории и его SHA в итоговом отчёте; она выполняет локальный критерий AD-008, не закрывая пункт автоматически. Публикация в GitHub не производится. Следующий содержательный этап — UX и дизайн Главной, только по отдельному заданию.
