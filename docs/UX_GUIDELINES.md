# UX — согласованные принципы

Дата: 14.11.2026. AS-IS baseline: `a1f5b8d6f8b2c8b43c6685c78a52abc2f210f07e` (`codex-dev`).

Главная — единое персональное интеллектуальное рабочее пространство руководителя ИТ-проектов без привязки к конкретной организации; чужой фирменный стиль не копируется (DEC-038). Первый экран: срочные проекты, задачи, риски; следующий — весь портфель; затем проектная детализация. Контекстные действия и переход к источнику. ИИ: блок на Главной + контекстные действия + отдельный каталог возможностей с честным статусом. Фиксированные блоки первой версии, desktop/mobile.

Не дублировать календарь встреч. Личная Kanban-доска РП, не задачи разработчиков. Закрытие задачи не закрывает исходную проблему автоматически.

Компоновка, прототипы и визуальная приёмка ещё не утверждены.
